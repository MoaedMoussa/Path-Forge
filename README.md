# PathForge Academy

PathForge Academy is an interactive computer science and algorithms learning platform. I built this to help students visualize and understand complex graph theory algorithms like A*, Dijkstra, BFS, and DFS through an interactive sandbox.

## Features

- **Courses**: Step-by-step interactive modules covering Data Structures and Graph Theory.
- **Pathfinding Lab**: A visual sandbox. Create walls, adjust node weights, and watch algorithms traverse the grid in real-time.
- **Study Groups**: Real-time collaborative coding and whiteboard sessions.
- **Level Gallery**: Browse and share custom pathfinding mazes with the community.
- **Study Deck**: Flashcards for CS fundamentals.

## Tech Stack

- React & TypeScript
- Vite
- Tailwind CSS & shadcn/ui
- Firebase (Firestore & Auth)
- Wouter for lightweight routing
- Framer Motion

## Getting Started

1. Clone the repository.
2. Install dependencies:

```bash
npm install
```

3. Set up your environment variables (see `.env.example`).
4. Start the development server:

```bash
npm run dev
```

## Deployment

This project is optimized for production deployment on Vercel, Netlify, or Firebase Hosting. A standard `npm run build` will output optimized static files to `dist/public`.
