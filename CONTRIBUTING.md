# Contributing to PathForge Academy

First off, thank you for considering contributing to PathForge! It's people like you that make open-source such a great community.

## 🛠️ Development Setup

1. Fork and clone the repo
2. Run `npm install` to install dependencies
3. Duplicate `.env.example` to `.env` and add your Firebase credentials
4. Run `npm run dev` to start the development server

## 📝 Coding Standards

- **TypeScript**: We strictly use TypeScript. Ensure all new components and utilities are properly typed.
- **Formatting**: We use Prettier. Run `npm run format` before committing.
- **Styling**: We use Tailwind CSS. Please utilize the standard utility classes rather than writing custom CSS files.

## 🚀 Pull Request Process

1. Ensure any install or build dependencies are removed before the end of the layer when doing a build.
2. Update the README.md with details of changes to the interface, this includes new environment variables, exposed ports, useful file locations and container parameters.
3. You may merge the Pull Request in once you have the sign-off of at least one other developer, or if you do not have permission to do that, you may request the reviewer to merge it for you.
